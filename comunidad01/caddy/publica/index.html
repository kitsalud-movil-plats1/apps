Certificado del kit de salud

Las páginas del kit que manejan datos (registro de pacientes y prerregistro) usan HTTPS con un certificado propio del kit. Si instala este certificado una vez, el navegador deja de mostrar la advertencia de seguridad.

Descargar el certificado

Android

  1. Descargue el certificado con el botón de arriba.
  2. Abra Ajustes, Seguridad, Más ajustes de seguridad (o Cifrado y credenciales) y luego Instalar un certificado, Certificado de CA.
  3. Elija el archivo raiz.crt de Descargas y confirme.

iPhone o iPad

  1. Descargue el certificado con Safari y acepte descargar el perfil.
  2. Abra Ajustes, Perfil descargado e Instalar.
  3. Abra Ajustes, General, Información, Ajustes de confianza de certificados y active Kit de salud movil - Raiz.

Windows

  1. Descargue el certificado y ábralo con doble clic.
  2. Elija Instalar certificado, Equipo local y la opción Colocar todos los certificados en el siguiente almacén.
  3. Seleccione Entidades de certificación raíz de confianza y termine. Firefox usa su propio almacén: Ajustes, Privacidad y seguridad, Ver certificados, Importar.

Linux

sudo cp raiz.crt /usr/local/share/ca-certificates/kit-salud.crt && sudo update-ca-certificates
